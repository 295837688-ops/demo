# 国债收益率曲线形态分析与策略回测

本仓库提供一个可直接运行的 Python 脚本，用于：

1. 分析收益率曲线形态（斜率、曲率）；
2. 基于 2s10s（10Y-2Y）构建均值回归交易信号；
3. 进行回测并生成中文报告。

## 快速开始

```bash
python yield_curve_strategy.py
```

运行后会在项目根目录输出 `report.md`，包含：
- 曲线形态分层（最陡/最平区间的未来变化）；
- 回测指标（累计收益、年化收益、波动、夏普、回撤、胜率等）；
- 实盘化建议（风控和增强方向）。

## 数据说明

脚本会优先尝试下载美国财政部 Daily Treasury Rates（2Y/5Y/10Y）。
若当前环境无法联网，会自动切换到**可复现的 synthetic 数据**，用于方法演示。

## 策略框架（简述）

- 形态指标：
  - `Slope = 10Y - 2Y`
  - `Curvature = 2*5Y - 2Y - 10Y`
- 信号：
  - 当 2s10s 的滚动 z-score > 1：做平（flattening）
  - 当 z-score < -1：做陡（steepening）
  - z-score 回到 0 附近平仓
- 成本：按换仓计入交易成本（默认 0.2bp）

> 该项目用于研究与教学演示，不构成投资建议。
